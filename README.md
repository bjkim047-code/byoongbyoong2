# progressboard

한 과목을 여러 반(예: 2-1 ~ 2-10)에 나눠 들어갈 때, 반마다 이번 주에 어느
차시를 나가야 하는지 한눈에 보여주는 Windows 데스크톱 진도표 앱입니다.
시간표와 진도 목록만 등록해두면 각 칸에 예상 진도가 자동으로 계산돼
표시되고, 수업을 마치고 돌아와 완료 표시만 눌러두면 됩니다.

## 주요 기능

- **주차별 시간표**: 왼쪽 목록에서 주차/기간을 선택하면 오른쪽에 그 주의
  월~금 x 1~N교시 시간표가 표시됩니다. 각 칸은 위쪽에 반(예: `2-3`), 아래쪽에
  그 반이 이번 슬롯에 나갈 것으로 예상되는 차시 제목이 표시되며, 둘 다
  가운데 정렬입니다. 칸 높이는 제목이 한 줄이든 두 줄이든 흔들리지 않도록
  고정돼 있습니다. 오늘 날짜인 요일은 초록색으로, 이미 지났는데 아직 상태
  표시를 하지 않은 칸은 주황색으로 강조됩니다.
- **시간표 기반 예상 진도 계산**: 표시되는 차시 번호는 원칙적으로 시간표만으로
  계산됩니다. 예를 들어 주당 2차시인 반은 1주차에 1·2차시, 3주차에 5·6차시가
  순서대로 표시됩니다. 예외 시간표로 특정 주의 수업 횟수가 줄어들거나, 특정
  수업을 "진행 못함"으로 표시하면, 그 다음부터는 번호가 그만큼 뒤로 밀립니다.
- **수업 상태 표시**: 칸을 클릭하면 **완료 / 시간 부족 / 진행 못함** 중
  하나를 고르는 작은 창이 뜹니다.
  - **완료·시간 부족**: 기록(✓ / △ 표시)만 남을 뿐, 다음 차시 번호에는
    영향을 주지 않습니다.
  - **진행 못함**: ✕ 표시가 남고, 그 반의 다음 수업부터 차시 번호가 하나씩
    뒤로 밀립니다(예: 월요일 1교시에 나갔어야 할 1차시를 "진행 못함"으로
    표시하면, 그 반의 다음 수업 시간에 2차시가 아니라 1차시가 다시
    표시됩니다).
  - 이미 상태가 있는 칸을 다시 클릭하면 "상태 해제"로 미정으로 되돌릴 수
    있습니다.
- **시간표 설정 메뉴**
  - **기본 설정**: 과목명, 담당 반 목록, 반별 주당 시수, 하루 최대 교시,
    총 차시 수(진도표 칸 개수), 1주차 시작일(월요일), 표시할 주차 수를
    설정합니다.
  - **기본 시간표 설정**: 요일 x 교시 표에서 어느 교시에 어느 반이 들어오는지
    지정합니다. 여기서 등록한 시간표는 예외가 없는 모든 주차에 공통으로
    적용됩니다. 표 맨 아래 "지우기" 버튼으로 그 요일 전체를 한 번에 비울 수
    있습니다.
  - **예외 시간표 설정**: 시험 기간, 휴업일 등으로 특정 주만 시간표가
    달라질 때, 그 주차를 선택해 그 주만의 시간표를 따로 등록합니다.
    "저장"으로 그 주의 예외를 등록하고, "기본 시간표 적용"으로 다시 기본
    시간표를 쓰게 되돌릴 수 있습니다.
  - **진도 설정**: 1차시부터 마지막 차시까지 차시별 제목과 수업 내용을
    입력합니다. 이 목록의 순서가 곧 시간표에 표시되는 예상 진도입니다.
- **팝업 창 하나로 동작**: "항상 위" 옵션으로 다른 창에 가려지지 않게 고정할
  수 있습니다. "윈도우 시작 시 자동 실행"을 체크하면 로그인할 때 자동으로
  이 창이 뜨도록 등록됩니다(Windows 전용 기능이며, 다른 OS에서는 체크박스가
  비활성화됩니다).

## 동작 방식(요약)

- 모든 반은 같은 진도 목록(1~N차시)을 공유합니다. 특정 (주차, 요일, 교시)
  칸에 표시되는 차시 번호는 "그 반이 그 주까지 시간표상 총 몇 번
  수업했는지"에서, "진행 못함"으로 표시된 수업 수를 뺀 값으로 정해집니다.
  완료·시간 부족 상태는 이 계산에 들어가지 않습니다.
- 시간표는 기본적으로 모든 주차에 동일하게 적용되지만, 특정 주에 대해
  예외 시간표를 등록해두면 그 주만 다른 시간표를 씁니다. 예외로 그 주의
  수업 횟수가 줄면, 이후 주차들의 차시 번호도 그만큼 뒤로 밀립니다.
- "진행 못함"으로 표시된 수업 자신은 원래 예정됐던 차시 번호를 그대로
  보여주고, 그 반의 그 다음 수업부터 번호가 하나씩 뒤로 밀립니다.

## 실행 방법

Python 3.9 이상과 표준 라이브러리에 포함된 Tkinter만 있으면 됩니다
(추가 설치 패키지 없음).

```bash
python run.py
```

또는 모듈로 실행:

```bash
PYTHONPATH=src python -m progressboard
```

데이터(설정, 시간표, 진도 상태)는 `~/.progressboard/data.json`에 저장됩니다.

### Windows용 실행 파일(.exe) 만들기

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name progressboard run.py
```

`dist/progressboard.exe`가 생성되며, 바탕화면에 두고 더블클릭해서 실행할 수
있습니다. 앱 안의 "윈도우 시작 시 자동 실행" 체크박스를 켜면 이 exe 경로가
레지스트리(로그인 시 자동 실행 목록)에 등록됩니다 — 별도로 시작프로그램
폴더에 바로가기를 만들 필요는 없습니다.

# progressboard

한 과목을 여러 반(예: 2-1 ~ 2-10)에 나눠 들어갈 때, 반마다 진도가 어디까지
나갔는지 잊지 않도록 도와주는 Windows 데스크톱 진도표 앱입니다. 수업에서
돌아와 완료 버튼을 누르면 그 반의 진도가 자동으로 다음 차시로 넘어가고,
이미 지나간 수업인데 아직 확인하지 않은 칸은 색으로 표시해 알려줍니다.

## 주요 기능

- **주차별 시간표**: 왼쪽 목록에서 주차/기간을 선택하면 오른쪽에 그 주의
  월~금 x 1~N교시 시간표가 표시됩니다. 각 칸은 위쪽에 반(예: `2-3`), 아래쪽에
  그 반이 다음에 나갈 차시 제목이 표시됩니다. 오늘 날짜인 요일은 초록색으로,
  이미 지났는데 아직 완료 확인을 하지 않은 칸은 주황색으로 강조됩니다.
- **반별 독립 진도 추적**: 10개 반이 각각 몇 차시까지 나갔는지 따로
  기억합니다. 특정 반 수업이 공휴일 등으로 빠지더라도 그 반만 진도가
  자연스럽게 밀립니다.
- **수동 확인 + 자동 제안**: 칸을 클릭하면 "이 수업을 완료 처리하고 다음
  진도로 넘어갈까요?"라고 물어본 뒤 진도를 넘깁니다. 실수로 눌렀다면 같은
  칸을 다시 눌러 완료를 취소하고 이전 진도로 되돌릴 수 있습니다.
- **시간표 설정 메뉴**
  - **기본 설정**: 과목명, 담당 반 목록, 반별 주당 시수, 하루 최대 교시,
    총 차시 수(진도표 칸 개수), 1주차 시작일(월요일), 표시할 주차 수를
    설정합니다.
  - **기본 시간표 설정**: 요일 x 교시 표에서 어느 교시에 어느 반이 들어오는지
    지정합니다. 여기서 등록한 시간표는 모든 주차에 공통으로 적용됩니다.
  - **진도 설정**: 1차시부터 마지막 차시까지 차시별 제목과 수업 내용을
    입력합니다. 이 목록이 각 반의 진도 포인터가 가리키는 실제 내용입니다.
- **팝업 창 하나로 동작**: "항상 위" 옵션으로 다른 창에 가려지지 않게 고정할
  수 있습니다.

## 동작 방식(요약)

- 모든 반은 같은 진도 목록(1~N차시)을 공유하지만, 반마다 "다음에 나갈 차시
  번호"를 따로 저장합니다.
- 시간표는 모든 주차에 동일하게 적용되는 하나의 기본 시간표를 사용합니다.
  주차 목록은 달력상의 실제 날짜(기간)를 보여주기 위한 것입니다.
- 특정 (날짜, 교시, 반) 조합을 완료 처리하면 그 조합을 기록해두고, 해당
  반의 진도를 한 차시 넘깁니다. 같은 조합을 다시 완료 처리해도 진도가 두
  번 넘어가지 않습니다.

## 실행 방법

Python 3.9 이상과 표준 라이브러리에 포함된 Tkinter만 있으면 됩니다
(추가 설치 패키지 없음).

```bash
python run.py
```

또는 모듈로 실행:

```bash
PYTHONPATH=src python -m progressboard
```

데이터(설정, 시간표, 진도 상태)는 `~/.progressboard/data.json`에 저장됩니다.

### Windows용 실행 파일(.exe) 만들기

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name progressboard run.py
```

`dist/progressboard.exe`가 생성되며, 바탕화면에 두고 더블클릭하거나 윈도우
시작프로그램 폴더에 바로가기를 등록해두면 로그인 시 자동으로 진도표가 뜨게
만들 수 있습니다.

- 특정 주에만 시간표를 다르게(시험 기간 등) 지정하는 주차별 예외 시간표

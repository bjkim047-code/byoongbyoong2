# progressboard

한 과목을 여러 반(예: 2-1 ~ 2-10)에 나눠 들어갈 때, 반마다 이번 주에 어느
차시를 나가야 하는지 한눈에 보여주는 Windows 데스크톱 진도표 앱입니다.
시간표와 진도 목록만 등록해두면 각 칸에 예상 진도가 자동으로 계산돼
표시되고, 수업을 마치고 돌아와 완료 표시만 눌러두면 됩니다.

## 주요 기능

- **주차별 시간표**: 왼쪽 목록에서 주차/기간을 선택하면 오른쪽에 그 주의
  월~금 x 1~N교시 시간표가 표시됩니다. 각 칸은 위쪽 가운데에 반(예: `2-3`),
  아래쪽 왼쪽 정렬로 그 반이 이번 슬롯에 나갈 것으로 예상되는 차시 제목이
  표시됩니다. 오늘 날짜인 요일은 초록색으로, 이미 지났는데 아직 완료
  확인을 하지 않은 칸은 주황색으로 강조됩니다.
- **시간표 기반 예상 진도 계산**: 표시되는 차시 번호는 완료 여부와 무관하게
  시간표만으로 계산됩니다. 예를 들어 주당 2차시인 반은 1주차에 1·2차시,
  3주차에 5·6차시가 순서대로 표시됩니다. 예외 시간표로 특정 주의 수업
  횟수가 줄어들면, 그 다음 주차부터는 번호가 줄어든 만큼 뒤로 밀립니다.
- **완료 표시**: 칸을 클릭하면 "이 수업을 완료 처리할까요?"라고 물어본 뒤
  체크 표시(✓)만 남깁니다. 클릭해도 표시되는 차시 내용 자체는 바뀌지
  않습니다. 실수로 눌렀다면 같은 칸을 다시 눌러 완료 표시를 취소할 수
  있습니다.
- **시간표 설정 메뉴**
  - **기본 설정**: 과목명, 담당 반 목록, 반별 주당 시수, 하루 최대 교시,
    총 차시 수(진도표 칸 개수), 1주차 시작일(월요일), 표시할 주차 수를
    설정합니다.
  - **기본 시간표 설정**: 요일 x 교시 표에서 어느 교시에 어느 반이 들어오는지
    지정합니다. 여기서 등록한 시간표는 예외가 없는 모든 주차에 공통으로
    적용됩니다.
  - **예외 시간표 설정**: 시험 기간, 휴업일 등으로 특정 주만 시간표가
    달라질 때, 그 주차를 선택해 그 주만의 시간표를 따로 등록합니다.
    "예외 해제" 버튼으로 다시 기본 시간표를 쓰게 되돌릴 수 있습니다.
  - **진도 설정**: 1차시부터 마지막 차시까지 차시별 제목과 수업 내용을
    입력합니다. 이 목록의 순서가 곧 시간표에 표시되는 예상 진도입니다.
- **팝업 창 하나로 동작**: "항상 위" 옵션으로 다른 창에 가려지지 않게 고정할
  수 있습니다.

## 동작 방식(요약)

- 모든 반은 같은 진도 목록(1~N차시)을 공유합니다. 특정 (주차, 요일, 교시)
  칸에 표시되는 차시 번호는 "그 반이 그 주까지 시간표상 총 몇 번
  수업했는지"를 계산해서 정해집니다 — 실제로 그 수업을 진행했는지와는
  무관합니다.
- 시간표는 기본적으로 모든 주차에 동일하게 적용되지만, 특정 주에 대해
  예외 시간표를 등록해두면 그 주만 다른 시간표를 씁니다. 예외로 그 주의
  수업 횟수가 줄면, 이후 주차들의 차시 번호도 그만큼 뒤로 밀립니다.
- "완료 표시"는 이 계산과는 별개로, 특정 (날짜, 교시, 반) 수업을 실제로
  진행했다는 개인적인 체크 기록일 뿐입니다.

## 실행 방법

Python 3.9 이상과 표준 라이브러리에 포함된 Tkinter만 있으면 됩니다
(추가 설치 패키지 없음).

```bash
python run.py
```

또는 모듈로 실행:

```bash
PYTHONPATH=src python -m progressboard
```

데이터(설정, 시간표, 진도 상태)는 `~/.progressboard/data.json`에 저장됩니다.

### Windows용 실행 파일(.exe) 만들기

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name progressboard run.py
```

`dist/progressboard.exe`가 생성되며, 바탕화면에 두고 더블클릭하거나 윈도우
시작프로그램 폴더에 바로가기를 등록해두면 로그인 시 자동으로 진도표가 뜨게
만들 수 있습니다.

## 테스트

주차/날짜 계산과 예상 진도 계산 로직에 대한 단위 테스트가 있습니다.
